    Where do I find my saves?

    PC (Steam)

    In Steam, right-click the game ➔ Manage ➔ Browse local files, then open gamedata\savedata. Typically:

    C:\Program Files (x86)\Steam\steamapps\common\Digimon Story Time Stranger\gamedata\savedata

    Nintendo Switch (JKSV)

    Back up the game with the JKSV homebrew app. Backups are stored on the SD card at sd:/JKSV/Digimon Story Time Stranger/<backup name>/.

    Which files are converted?

    Every 0000.bin-style save and every slot_0000.bin-style slot file directly inside the input folder. Subfolders are not searched.
